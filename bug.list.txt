[FIXED] BUG-037: Memex Session and Web Explorer progress jumping and premature 100% resolution reporting
  Fixed: 2026-08-30 (d9eb5cb) — Unify download resolution telemetry and SSE schemas between Mem-Gate and Web Explorer. Calculate deterministic expected total block count and byte sizing upfront in net/memex_v2/session.go from root MemFSNode/Descriptor metadata. Prevent premature 100% progress reporting during multi-level DAG expansion. Update SvelteKit explorer frontend to smoothly track byte/block progress and stable piece mapping without destructive grid resets.

[FIXED] BUG-036: Circuit relay v2 hop service deactivation on long-running nodes due to AutoNAT reachability fluctuation
  Fixed: 2026-08-18 — Add ForcePublic configuration (and auto-apply for RelayService nodes), locking host reachability to ReachabilityPublic permanently. Prevents transient AutoNAT probe/observer drops after 10-24h from shutting down the Circuit Relay v2 hop service. Disables AutoRelay client on relay providers. Added unit tests in net/host/nat_test.go.

[FIXED] TASK-P2-PERF-002: BitTorrent-Style Adaptive Procedural Block Sizing
  Fixed: 2026-08-07 — Implement AdaptiveBlockSize in core/chunk (256 KiB up to 4 MiB based on content size) and wire into core/ingest. Cuts DB write operations for multi-gigabyte files by ~90% (e.g. 71,000 writes down to 8,800 writes for 1.24 GB), eliminating BadgerDB WAL flushing freezes and disk thrashing. Added unit tests in core/chunk/adaptive_test.go.

[FIXED] TASK-P2-PERF-001: Single-Pass Inline Reed-Solomon Erasure Coding
  Fixed: 2026-08-07 — Eliminate second-pass disk-read store.Walk loop during daemon ingestion. Wire Reed-Solomon 10+4 parity generation directly into memfs.Builder and core/ingest, encoding chunks in RAM as they are created. Reduces large-file ingestion time by ~60% with zero duplicate disk reads.

[FIXED] TASK-P2-BUG-002: Make MemFS File Trees Fully Recursive and Streaming for Very Large Objects
  Fixed: 2026-08-07 — Refactor core/memfs/builder.go AddFile to use streaming memfsLevelStack bottom-up reduction. Memory usage remains bounded O(Fanout * depth) for arbitrary multi-terabyte inputs, every MemFSNode respects dag.Fanout (174), and resolution via memfs.Resolver/reader remains byte-identical. Added streaming recursive tree tests in core/memfs/builder_streaming_test.go.

[FIXED] TASK-P2-BUG-001: Propagate Seal and ObjectInfo Persistence Failures Instead of Returning False Success

Ensure DHT provider announcements and root indexing only execute after durable metadata and seal completion. Added fault-injection tests in core/ingest/ingest_fault_test.go and cmd/membuss/daemon/ingest_fault_test.go.
